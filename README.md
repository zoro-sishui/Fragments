# Fragements

The main components required to complete this lab work are:

1.Node.js<br>
2.Visual code extension like: <br>
&nbsp;&nbsp;i.ESLint<br>
&nbsp;&nbsp;ii.Prettier - Code Formatter<br>
&nbsp;&nbsp;iii.Code Spell Checker<br>
3.git<br> 
4.curl

<strong>To clone this repo</strong><br>
```git clone git@github.com:zoro-sishui/Fragements.git```

<hr>
<strong>Running the Server</strong><br>
1. Normal mode <br>
```bash npm start```
<br>
To test if its working on not, we can check it in the [http://localhost:8080](http://locahost:8080)
<br>
2. Dev mode <br>
```npm run dev ```
<br>
3. Debug <br>
We can use cli `npm run debug` or we can click on the code runner button an choose to run with npm debugger.<br>
3. Lint <br>
```npm run lint```
<br>
4.Curl <br>
```curl localhost:8080```
<br>
curl with jq<br>
```curl -s localhost:8080 |jq```
<br>
Curl with I flag<br>
```curl -i localhost:8080```
