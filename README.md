# Fragements

This repository contains the lab work for **Fragments** below are the basic requirements and the process the run each process.

---
## Required

1. **Node.js**  
2. **Visual Studio Code** extensions:
   - ESLint
   - Prettier - Code Formatter
   - Code Spell Checker  
3. **git**  
4. **curl**
5. **jq**

---

## Setup

Clone the repository:

```git clone git@github.com:zoro-sishui/Fragements.git ```

---
## Running the Server

*Normal mode*

```npm start```

To test if its working on not, we can check it in the [http://localhost:8080](http://locahost:8080)

---

*Dev mode*

```npm run dev ```

---

*Debug*

We can use cli `npm run debug` or we can click on the code runner button an choose to run with npm debugger.

---

*Lint* 

```npm run lint```

---

*Curl*

```curl localhost:8080```

----

*curl with jq*

```curl -s localhost:8080 |jq```

----

*Curl with I flag*

```curl -i localhost:8080```
